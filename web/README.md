# web — the new Nazareth Holy Cross site

Next.js 16 + TypeScript + next-intl (11 languages, Hebrew/Arabic right-to-left).
How we work, environments and rules: [`../docs/ENGINEERING.md`](../docs/ENGINEERING.md).

```bash
npm install
npm run dev          # http://localhost:3000/en
npm run check        # lint + types + unit tests + production build
npm run test:e2e     # Playwright against the production build
```
